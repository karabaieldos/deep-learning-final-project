# Data Directory

This folder is intended to store the raw datasets for the Toxic Comment Classification project. 

**⚠️ Note: Large CSV files are not committed to this repository due to GitHub size limits.**

## How to get the data

To run the notebooks and scripts in this project, you need to download the dataset manually and place the files in this directory.

1. Go to the [Jigsaw Toxic Comment Classification Challenge](https://www.kaggle.com/c/jigsaw-toxic-comment-classification-challenge/data) on Kaggle.
2. Accept the competition rules.
3. Download the data archive.
4. Extract the following files and place them directly in this `data/` folder:
   * `train.csv`
   * `test.csv`
   * `test_labels.csv`
